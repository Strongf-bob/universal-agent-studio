# Короткий стартовый промпт для Codex

Привет. Я хочу начать проект **Universal Agent Studio** — универсальную web-платформу для визуального создания, запуска, публикации и улучшения AI-агентов.

Ключевая идея: простой пользователь видит только понятные настройки и готовое web-приложение агента, а продвинутый может раскрыть тот же агент до n8n-подобного графа, моделей, промптов, skills, кода, API, traces, evals и версий. Платформа должна быть независимой от конкретного LLM-провайдера, поддерживать переиспользуемые capability-пакеты, RAG, интеграции, RU/EN, Web + API и контролируемый autoresearch.

В репозитории будут базовые документы: `PRODUCT.md`, `ARCHITECTURE.md`, `DESIGN.md`, `AGENTS.md`, `SECURITY.md`, `EVALS.md`, `LOCALIZATION.md`, `OPEN_SOURCE_POLICY.md` и `ROADMAP.md`.

**Пока не пиши production-код.** Сначала прочитай документы и ответь:

1. Как ты понял продукт и его главные архитектурные границы?
2. Какие противоречия, риски или недостающие решения мешают уверенно начать?
3. Каких файлов, схем, доступов или примеров тебе не хватает?
4. Какую структуру репозитория и первый end-to-end vertical slice ты предлагаешь?
5. Готов ли ты после согласования начать с контрактов и ADR, а не с несвязанного UI-scaffolding?

Ответ должен быть конкретным: список решений, блокеров и рекомендуемый первый план работ.
